\sectiontitle{Provenance}
The current parameter snapshot copies 189 generated values from the source model. It includes 22 external data-backed values and 158 static single-value assumptions. 19 country-bound parameters are made explicit in the synthetic reference set.

\sectiontitle{Internal validity}
The current-reference test materialises the model from the snapshot and runs it for Ethiopia. The synthetic-reference test materialises the model with the synthetic reference country where possible. These tests are execution checks, not external scientific validation.

\sectiontitle{Limits}
This is the first conservative migration. It preserves non-country embedded parameters and makes the reference-set machinery explicit. The next stronger version should replace disease, risk-factor, and cost inputs with declared synthetic fixture values where those are intended to be stable across evidence updates.
